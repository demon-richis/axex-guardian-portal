## 5. Captcha and Orbit

- Cloudflare Turnstile is called by the portal Siteverify endpoint. The portal sends the secret, challenge response, action, hostname/cdata checks, and the client IP as `remoteip` when available. The repository does not show a durable Turnstile response store.
- AxexOrbit receives signed sessions and challenge answers. Its core stores session/challenge/pass state in signed tokens and uses PostgreSQL only for used token identifiers (session/challenge/pass JTIs) plus expiry. Development uses a bounded expiring memory store. Orbit does not show durable browser fingerprints, raw mouse paths, IP addresses, challenge images, answers, or user profiles.
- Orbit logs contain request IDs and coarse rejection reasons, with authorization and cookies redacted. Expired replay rows are periodically removed.
